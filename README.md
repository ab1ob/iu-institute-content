# مصدر محتوى موقع معهد البحوث والدراسات الإستشارية

> **مسودة قيد المراجعة، غير معتمدة للنشر الرسمي بعد.**
> هذا المستودع يحمل نصوص صفحات مقترحة، ولا يمثل الموقع الرسمي للجامعة الإسلامية بالمدينة المنورة.

## ما هذا الملف

`content.json` يحمل نصوص صفحات الموقع كاملة. التطبيق الذي يعرض هذه الصفحات لا يحمل نصا،
بل يقرأ من هنا. لذلك أي تعديل في هذا الملف يظهر في الموقع خلال دقائق، بلا إعادة نشر
للتطبيق وبلا تدخل من الجهة المستضيفة.

عنوان القراءة:

```
https://raw.githubusercontent.com/ab1ob/iu-institute-content/main/content.json
```

## بنية الملف

```
site      اسم الجهة والهاتف والبريد
nav       التبويبات وفروعها
pages[]   صفحة لكل عنصر
  slug        مسارها في الموقع
  title       العنوان في أعلى الصفحة
  lead        السطر تحت العنوان
  description وصفها لمحركات البحث
  crumb       اسمها في مسار التنقل
  nav         التبويب الذي يضيء لها
  sections[]  بطاقات الصفحة: heading عنوان البطاقة، html متنها
```

## كيف يحدث

النصوص تولد من مولدات المحتوى في مشروع الموقع، ثم تصدر إلى هنا بأمر واحد.
**لا يحرر هذا الملف يدويا**، لأن أي تعديل مباشر فيه يضيع عند التصدير التالي.

## ما لا يوضع هنا أبدا

أرقام النظام التشغيلية، وبيانات الموظفين، وطلبات المستفيدين، وأي مادة غير معدة
للنشر العام. محتوى هذا الملف هو نفسه النص الذي يقرؤه زائر الموقع، لا أكثر.
